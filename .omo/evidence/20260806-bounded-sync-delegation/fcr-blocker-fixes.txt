# FCR blocker fixes

## Findings and changes

1. Continuation adoption passed a root session ID without owning a prior descendant reservation. Added required `rootDescendantAlreadyReserved`. `executeSyncContinuation` passes `false`; `adoptRunningSession()` registers before `addTask()` only for that branch. `executeSyncTask` passes `true`, preserving its committed spawn reservation.
2. Repeated adoption could mint two `bg_` tasks for one live session. `adoptRunningSession()` now returns existing nonterminal task before any root registration, history recording, or parent marker update.
3. Poller checked automatic wall-clock yield before user abort. Abort handling now executes first; expired deadline yields only when parent was not aborted.
4. Removed trailing whitespace from lines 10 and 24 of `task-7-plumbing-red-green.txt`.
