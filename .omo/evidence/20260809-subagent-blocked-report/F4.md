Base `constants.ts` already held `DEFAULT_STALE_TIMEOUT_MS = 2_700_000`, `DEFAULT_MESSAGE_STALENESS_TIMEOUT_MS = 3_600_000`, `DEFAULT_MAX_TOOL_CALLS = 4000`, `TERMINAL_TASK_TTL_MS = 30 * 60 * 1000`. A `superRefine` enforces `blockedRewakeMs < blockedExpiryMs < TERMINAL_TASK_TTL_MS`.

The `-` side of the diff contains no removed numeric constant other than those three doc strings.
