### `findBySession?.` reasoning

`ExecutorContext.manager` is concrete in production and always defines `findBySession`. Existing broad unit-test stubs omit it. Optional call prevents unrelated legacy tests from failing but treats such incomplete stubs as adopted because `undefined === undefined`; this is test-only behavior. Production behavior remains exact pre-resume observation. Changing every broad fixture is outside assigned file scope, so optional call remains deliberately scoped compatibility.
